# Drools 规则引擎学习计划（从 0 到 1）

> 学员定位：具备 Java 基础的工程师，想从零掌握 Drools 规则引擎并落地到 Spring Boot 项目。

## 一、学习目标

学完本计划后，你将能够：

1. 理解规则引擎的定位、Rete 算法原理、Drools 生态体系。
2. 熟练编写 DRL 规则文件，掌握 LHS（条件）/ RHS（动作）全部核心语法。
3. 用传统 KieSession API 和现代 Rule Unit API 两种方式执行规则。
4. 将 Drools 集成进 Spring Boot 4.1.0 项目，支持规则热加载。
5. 独立完成一个电商促销 / 金融风控类的综合实战项目。

## 三、学习路线（8 个阶段）

### 阶段 0：概念认知与环境准备

- 规则引擎是什么、解决什么问题（if-else 的困境）
- Rete 算法核心思想（正向链推理）
- Drools 生态全景（Drools / jBPM / Kogito / DMN / Fusion）
- 环境搭建与第一个项目骨架
- ✅ 产出：能解释"为什么用规则引擎"

### 阶段 1：核心概念与第一个规则（Hello Drools）

- KieServices / KieContainer / KieBase / KieSession 四大组件
- Fact（事实对象）与 JavaBean 规范
- DRL 文件结构：package / import / rule / when / then / end
- `insert` / `fireAllRules` / `dispose`
- ✅ 产出：可运行的 Hello Drools 示例

DRL 的代码块是靠关键字配对来划分的，不是靠缩进。所以缩进纯粹是"给人看的格式"，对引擎毫无影响。

### 阶段 2：DRL 语法进阶（LHS 条件）

- Pattern 匹配与字段约束
- 变量绑定 `$var`、比较/正则/集合运算符
- 逻辑连接：and / or / not / exists / forall
- 集合操作：from / collect / accumulate
- ✅ 产出：能写出复杂的条件匹配规则

`and`和`&&`的区别：

and只能出现在条件与条件之间，&&只能出现在字段之间。

```.drools
// ✅ 写法1：换行（什么都不写，默认就是 and）—— 最常用
exists Order(user == $u)
not Order(user == $u, refunded == false)

// ✅ 写法2：显式写 and —— 也合法（我已实测跑通）
exists Order(user == $u) and not Order(user == $u, refunded == false)

// ❌ 写法3：用 && —— 报错，因为 && 连接不了条件元素
exists Order(user == $u) && not Order(user == $u, refunded == false)
```

一句话总结：`括号内`用符号（`&&`、`||`），`括号外`用单词（`and`、`or`、`not`、`exists`）

### 阶段 3：RHS 动作与事实变更

- insert / modify / update / delete(retract)
- 规则属性：salience / no-loop / lock-on-active / agenda-group / activation-group / date-effective / enabled
- 理解并规避无限循环
- ✅ 产出：掌握规则执行顺序控制

### 阶段 4：规则进阶特性

- Global 全局变量
- Query 查询
- Function 自定义函数
- 决策表（Decision Table，Excel 编写规则）
- ✅ 产出：能用决策表让业务人员维护规则

### 阶段 5：Rule Unit（现代推荐写法）

- RuleUnit / DataSource 概念
- RuleUnitProvider / RuleUnitInstance 生命周期
- 与传统 KieSession 的对比与选型
- ✅ 产出：用 Rule Unit 重写规则

### 阶段 6：Spring Boot 4.1.0 集成

- 官方 Starter：`drools-rules-spring-boot-starter`
- 手动集成方式（KieContainer 注册为 Spring Bean）
- 规则热加载与动态更新、内存泄漏防护
- ✅ 产出：Spring Boot 规则服务

### 阶段 7：综合实战项目

- 项目 A：电商促销 / 优惠券引擎
- 项目 B：金融风控 / 信贷审批
- ✅ 产出：一个完整的规则驱动应用

### 阶段 8：进阶与生态

- 规则测试与 Scenario Simulation
- DMN 决策模型入门
- Drools Fusion / CEP 复杂事件处理
- 性能调优与生产实践
- ✅ 产出：形成完整的 Drools 知识体系

## 四、学习方式

每个阶段遵循「**讲解概念 → 动手写代码 → 运行验证 → 小结**」的闭环，代码全部落在本仓库对应目录下，可随时回溯复习。
